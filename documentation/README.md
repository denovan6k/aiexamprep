# Knorvex documentation

Docusaurus site for Knorvex **Guides** (students) and **Developers** (contributors).

## Local

```powershell
pnpm install
pnpm start
```

## Build

```powershell
pnpm build
pnpm serve
```

Content lives in `docs/`. Site config is `docusaurus.config.ts`. Branding is in `src/css/custom.css`.

When you ship product features, update the matching guides or developer pages — see [Docs workflow](./docs/developers/docs-workflow.md).
