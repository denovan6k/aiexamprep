# Professor Agents

Professor Agents capture how your examiner asks questions — tone, formats, favourite traps, and marking strictness — so generated practice feels like the real course.

## Why use an agent

Generic AI quizzes often miss the voice of your lecturer. An agent lets you describe that style once in plain English, then reuse it whenever you generate quizzes or chat.

## Create an agent

1. Open **Agents** in the workspace sidebar (or the Agent Builder flow).
2. Describe your examiner: question formats, how harsh marking is, topics they emphasise, common distractors.
3. Save the profile.
4. Select that agent when generating practice or opening agent-scoped chat.

## Suggested journey

1. Open the Agent Builder.
2. Describe your examiner in plain English.
3. Save the question style you expect.
4. Select that profile when generating quizzes.
5. Read feedback that points to the mark you missed.

## Tips

- Keep one agent per lecturer or certification style rather than one mega-prompt for everything.
- Update the agent after a real exam or marked assignment if you learned new preferences.
- Share agents with a study group when you want consistent question style across the cohort — without sharing raw uploads.
