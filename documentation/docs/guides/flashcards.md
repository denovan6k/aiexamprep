# Flashcards

Flashcards are for spaced, focused recall — definitions, pathways, and the facts you keep missing on quizzes.

## Create a deck

- Generate from [materials](./materials-and-courses) or chat (“make a deck from chapter 2”).
- Build or edit decks manually in the flashcard builder.
- Turn **quiz misses** into cards so you revise what actually tripped you up.

## Study session

1. Open a deck from **Flashcards**.
2. Work through the session; mark cards you know vs still shaky.
3. Use the session summary to see what to revisit.
4. Return later — weak cards matter more than finishing every card once.

## Tips

- Prefer short fronts and precise backs.
- One concept per card beats multi-part walls of text.
- Pair decks with a [Professor Agent](./professor-agents) style when generating so terminology matches your course.
