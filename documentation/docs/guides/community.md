# Community

Study with others without exposing every raw file. Community groups support discovery, discussion threads, and shared practice resources.

## What you can do

- Discover public groups or join private ones
- Start discussion threads with replies and pinned posts
- Share quizzes, flashcard decks, and professor agents
- Use roles: owner, moderator, member
- Report content into the moderation queue
- Search across groups and threads

## Sharing rules

- **Share** quizzes, decks, and saved exam styles with your group.
- **Raw uploads stay private** unless you choose otherwise.
- Private groups are visible only to members.
- Shared resources never leak source files without owner consent.

## Good group hygiene

- Agree what is OK to share (practice only vs annotated notes).
- Prefer shared agents for consistent question style across the cohort.
- Report spam or academic integrity issues through in-product moderation tools.
